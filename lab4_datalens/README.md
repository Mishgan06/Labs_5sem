В этой версии сохранены 10 собственных снимков пользователя, заполнены подтверждённые наблюдения и исправлено оформление. Оставшиеся проверки перечислены отдельно. Описание и ссылки ниже относятся к первоначальному шаблону без снимков.

- [Предпросмотр отчёта PDF](lab4_datalens_report_preview.pdf).

Подготовлено по приложенному заданию «Практическая работа 4. Знакомство с Yandex DataLens». Титульный лист исключён по запросу пользователя; при необходимости его добавляют отдельно перед сдачей.

Содержательная часть: подключение PostgreSQL, типы полей датасета, COUNTD идентификатора по классам, карта с размером точек 5 и SUM комнат, самостоятельный чарт SUM комнат по районам, селектор с множественным выбором, Markdown-вывод, публикация и проверка без входа.

Снимки DataLens не вставлены: пользователь сообщил, что дашборд ещё не создан. Из среды подготовки домен datalens.ru отвечал отказом прокси (403), а прямой TCP-доступ к учебному серверу PostgreSQL получил Connection refused. Это не доказывает недоступность подключения из самого DataLens. Интерфейс, данные и опубликованная ссылка в аккаунте пользователя не проверены. Девять мест для снимков подписаны; инструкция объясняет, как получить каждый кадр.

В отчёте дополнительно нужно заполнить фактическое наблюдение по качеству данных, выбранные районы и публичную ссылку. Численные результаты и обнаруженные ошибки не выдуманы.

Материалы:
- `materials/chart_settings.md` — настройки трёх чартов и селектора;
- `materials/dashboard_conclusion.md` — Markdown для текстового блока (дописать фактическое наблюдение);
- `materials/quality_checks.sql` — дополнительные read-only SELECT-запросы; не выполнялись в этой среде.

Пароль учебного источника не опубликован: возьмите его из исходной методички, с. 4. Не показывайте пароль на снимках.

В методичке название воркбука «Практическая работа 1» не совпадает с номером работы; в комплекте оно сохранено буквально с пояснением. Для селектора используется реальный общий датасет `pr_1_gostinicy`: упоминание «датасет cloud_lab» в методичке расходится с её указаниями по созданию датасета.
