Часть 1: функция make_data из методички, n=100, seed=42; StandardScaler; K-means fit_predict для k=3,2,4; центры в исходных координатах; силуэт; локоть k=1…10. Силуэты: k=2 — 0,4997; k=3 — 0,7186; k=4 — 0,5938.

Перебор k=2…10 по полному силуэту, random_state=42, n_init=20. Для основной матрицы оба метода выбрали k=2. K-means: силуэт 0,083981, ARI 0,000069; Ward: силуэт 0,060446, ARI −0,000973.
