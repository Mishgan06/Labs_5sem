## Содержание и фактические результаты
Часть 1: функция make_data из методички, n=100, seed=42; StandardScaler; K-means fit_predict для k=3,2,4; центры в исходных координатах; силуэт; локоть k=1…10. Силуэты: k=2 — 0,4997; k=3 — 0,7186; k=4 — 0,5938.

Часть 2: все 3024 транзакции, 135 мошеннических (4,46%). Исходных пропусков и полных дубликатов нет. 130 отрицательных сумм и 24 отрицательных времени заменены медианами 48,335 и 142. Крупные положительные значения не удалены. Для суммы и времени применено log1p, далее StandardScaler числовых признаков. Категории закодированы get_dummies без drop_first и без дополнительного масштабирования бинарных столбцов. Fraud исключён из X.

Перебор k=2…10 по полному силуэту, random_state=42, n_init=20. Для основной матрицы оба метода выбрали k=2. K-means: силуэт 0,083981, ARI 0,000069; Ward: силуэт 0,060446, ARI −0,000973. Группы слабо разделены и почти не воспроизводят Fraud. Оценки описывают текущие данные, не являются независимой проверкой классификатора мошенничества.

Дендрограмма рассчитана на всех строках и усечена при отображении до последних 25 узлов. Показаны все средние исходных числовых признаков и доли категорий. Номера кластеров не являются номерами известных классов. Дополнительно: две проекции, contingency_matrix, общая таблица пяти метрик и сравнение с числовыми признаками без категорий.
