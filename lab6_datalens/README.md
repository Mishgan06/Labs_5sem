# Работа № 6 — анализ ДТП Санкт-Петербурга

**Статус: подготовлен проект отчёта; DataLens и исходная БД самостоятельно не выполнены из-за отсутствия доступа.**

- [Отчёт Word с вашим редактируемым титулом](lab6_datalens_report.docx)
- [Предпросмотр отчёта PDF](lab6_datalens_report_preview.pdf)
- [Подробная инструкция PDF с примерами интерфейса](lab6_datalens_guide.pdf)
- [Весь комплект ZIP](lab6_datalens_complete.zip)

Отчёт — 11 страниц до вставки снимков, инструкция — 11 страниц. Основной текст: Times New Roman 14 пт, интервал 1,5, первая строка 1,25 см; рамки рисунков и подписи по центру. Сохранён пользовательский титул с Д. С. Лисюковым, курсом «Облачные технологии и сервисы», группой 4417; номер и тема изменены на работу № 6.

Что подготовлено: семь чартов, четыре верхних селектора, формулы NULL/геоточки/частей даты/COUNTD, схема проверки сумм погибших и пострадавших, 13 подписанных мест для собственных снимков и аналитическая таблица.

Почему нет настоящих снимков: datalens.ru вернул HTTP CONNECT 403 от сетевого прокси, к аккаунту пользователя нет подключённой авторизации; в политике среды отсутствуют TCP-разрешения к учебной БД. Это ограничение данной среды, а не результат проверки из пользовательского DataLens. Пароль подключения в файлы не включён. Численные результаты и публичная ссылка не выдуманы.

Иллюстрации инструкции взяты из предоставленной методички и явно подписаны как примеры, не результаты пользователя. В самом отчёте они не подставлены вместо собственных снимков.

Методические уточнения:
- Исходная таблица в задании не названа. Файл `materials/discover_source.sql` помогает найти таблицу по известным полям (только SELECT).
- Стаж с текстом «Не указан» требует STR числовой ветви; исходный числовой стаж сохраняется.
- В формуле DATEPART с hour убран лишний пробел.
- SUM(dead_count) — погибшие люди, а не число происшествий с погибшими.
- COUNTD(injured_count) не даёт число пострадавших; SUM допустима только после проверки зерна. Уникальность людей между разными событиями без идентификатора человека не устанавливается.
- При повторяющихся участниках суммы могут многократно завышаться; нужна проверка уровня события.
- Карта фильтруется по категории «Наезд на велосипедиста», даже если на иллюстрации методички показан район.

Материалы: `formulas.md`, `dashboard_text.md`, `discover_source.sql`, `audit_dtp_csv.py`.

Для независимой проверки фактической CSV-выгрузки:

```sh
python materials/audit_dtp_csv.py dtp.csv --out dtp_audit.json
```

Скрипт вычисляет только поддерживаемые итоги по событиям и удерживает суммы при конфликтующих/пустых численностях; не выполняет сетевых запросов и не изменяет источник. Самопроверка на синтетических данных:

```sh
python materials/audit_dtp_csv.py --self-test
```

Для завершения нужны собственное подключение DataLens, реальные снимки/CSV и публичная ссылка. Готовность шаблона не означает готовность лабораторной к сдаче.
