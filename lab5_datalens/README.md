Отчёт: 10 страниц до вставки собственных снимков. Титул перенесён из предоставленного пользователем шаблона: ассистент Д. С. Лисюков, курс «Облачные технологии и сервисы», группа 4417. Основное оформление сохранено из исправленной работы № 4: Times New Roman 14 пт, интервал 1,5, абзац 1,25 см, поля 30/15/20/20 мм.

Инструкция: 10 страниц с точными действиями, местами кнопок, формулами, фильтрами, сортировкой и нумерацией девяти снимков. Иллюстрации заимствованы из предоставленной методички и явно обозначены как ориентиры, а не собственные результаты.

Обязательные объекты: подключение «Файлы» с windows-1251, `;`, заголовком; датасет kinopoisk_data; три диаграммы и таблица; три верхних селектора country/producer/year_release; публичный дашборд. Воркбук «Практическая работа 2» — название из методички к работе № 5.

В комплект включены `materials/formulas.md`, `materials/dashboard_text.md` и дополнительный анализатор `materials/analyze_csv.py`. Никаких сторонних Python-пакетов ему не требуется:

```sh
python materials/analyze_csv.py kinopoisk-top250.csv --out kinopoisk_analysis
```

Скрипт создаёт analysis.json и answers.md по реальному файлу: считает уникальные названия, все равные максимумы, внутренние пропуски лет, лидеров стран/режиссёров и максимум для точного country=Россия. Составные страны и СССР не объединяются с Россией молча. Самопроверка алгоритма:

```sh
python materials/analyze_csv.py --self-test
```

Методические уточнения: нужны все три селектора (в тексте задания один из них пропущен на последующих шагах); в примере формулы на картинке COUNT расходится с текстовым COUNTD — используем COUNTD; общий порог режиссёра при цветовой детализации по стране требует контроля уровня агрегации, для этого предложен FIXED [producer].

Исходный CSV пока не предоставлен. Его ссылка на Яндекс Диске заблокирована сетевой политикой среды подготовки (403), поэтому реальные данные не подменялись и численные ответы на пять вопросов не выдуманы. Собственные снимки DataLens и публичная ссылка также не созданы. В отчёте оставлены явные места для них и для фактических ответов. После получения CSV ответы можно заполнить; гипотеза о причинах пропуска лет не выдаётся за доказанный исторический факт.
