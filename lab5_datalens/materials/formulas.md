# Формулы и настройки для работы № 5

Датасет: kinopoisk_data. Исходные имена полей не переименовывать глобально до ввода формул. Русские названия задавать локально в чартах.

## Количество фильмов
```text
COUNTD(STR([movie title]))
```

## Количество больше 5 — для стран
```text
COUNTD([movie title]) > 5
```
Фильтр: Равно → True / Истина. Строго больше 5 означает от 6, а не от 5.

В рисунке 4 методички виден COUNT, хотя текст задания требует COUNTD. Здесь используется COUNTD по тексту задания, чтобы считать уникальные названия.

## Количество фильмов режиссёра — для сортировки и порога
```text
COUNTD([movie title] FIXED [producer])
```

## Количество больше 3 — режиссёр в целом
```text
COUNTD([movie title] FIXED [producer]) > 3
```
Фильтр: Равно → True / Истина. Строго больше 3 означает от 4.

Зачем FIXED: при добавлении country в Цвета детализация становится producer + country. Обычный COUNTD([movie title]) > 3 тогда может отфильтровать отдельные сегменты страны вместо режиссёра в целом. FIXED сохраняет уровень producer. По оси X и в подписях остаётся обычное «Количество фильмов», чтобы корректно показать страновые сегменты. Проверьте общий итог режиссёра по таблице без country, особенно после включения селекторов.

Если вам нужен буквальный вариант формулы из аналогии с заданием 4, это COUNTD([movie title]) > 3. При country в Цветах он требует отдельной проверки уровня группировки; не используйте его вслепую для общего порога режиссёра.

## Карта полей
| Чарт | X | Y | Цвета | Подписи | Фильтр |
|---|---|---|---|---|---|
| Количество фильмов по годам | year_release, дискретно | Количество фильмов | постоянный нестандартный цвет | Количество фильмов | нет |
| Страны с количеством фильмов больше 5 | Количество фильмов | country | country | Количество фильмов, внутри полос | Количество больше 5 = True |
| Режиссёры с количеством фильмов больше 3 | Количество фильмов | producer | country | Количество фильмов | Количество больше 3 = True |
| Информация о фильмах | Таблица: movie title, year_release, country, producer, rating_top, rating_ball | — | — | — | без порогов >5 и >3 |

Сортировка стран: Количество фильмов ↓. Сортировка режиссёров: Количество фильмов режиссёра ↓.

## Селекторы в одной верхней строке
- Страна-производитель → country;
- Режиссёр → producer;
- Год выхода → year_release.

В задании 7 сначала названы страна и режиссёр, затем дополнительно год. Поэтому нужны все три.
