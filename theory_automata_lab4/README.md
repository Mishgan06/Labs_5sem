## Проверка модели

1. Открыть `lab4_variant13.jff` через File → Open в JFLAP.
2. В настройках критериев принятия включить Final State и отключить Halting. Начальное состояние q0, конечное q8.
3. Выбрать Input → Multiple Run (Transducer), ввести слова, нажать Run Inputs. Например, `abcd` даёт `abcd=abcd`, `ba` — `ba=ba`; пустое поле даёт `=`. Буквальный символ λ не вводится.
4. Для просмотра ленты выбрать Input → Step и ввод `abcd`. После 80 переходов получается `abcd=abcd`, головка стоит над первым символом. Промежуточные метки A, B, C, D в результате отсутствуют.
5. `ab1`, `a=b`, `Ac` и `012` должны давать Reject. Такие символы не относятся к входному алфавиту.

Модель содержит 9 состояний, 53 перехода и одну ленту. В графическом JFLAP 7.0 (jflaplib-core 1.3) фактически выполнены 20 тестов и пошаговые разборы `abcd` и `ab1`. Скриншоты работающей программы вставлены в отчёт; для ленты использованы подписанные фрагменты окон. Дополнительно программно проверены все 5461 слово длиной до 6.
