# Лабораторная работа №2 — мастерская ремонта техники

Разработка диаграмм поведения по методическим указаниям Н. В. Барклаевской, 2026. Продолжение первой работы по информационной системе мастерской ремонта техники.

- [Отчёт Word](Отчет_ЛР2_Мастерская.docx)
- [Отчёт PDF](Отчет_ЛР2_Мастерская.pdf)
- [Проект StarUML: три диаграммы](Мастерская_ЛР2.mdj)
- [Все диаграммы PDF](Диаграммы_ЛР2.pdf)
- [Памятка для демонстрации](Как_показать_работу.txt)

В каталоге `diagrams/` каждая диаграмма представлена отдельно в форматах MDJ, SVG, PNG и PDF:

1. Состояния объекта «Заказ на ремонт».
2. Активность «Оформление заявки на ремонт» с выделением сущностей.
3. Активность с дорожками «Диагностика и согласование стоимости» с выделением сущностей.

Отчёт содержит 10 страниц. Титул и стиль сохранены из первой работы: группа 4417, М. П. Курбатов, кафедра 41.

**Ограничение:** изображения в отчёте — визуализации диаграмм, а не скриншоты интерфейса StarUML. Официальный сайт загрузки программы был недоступен из среды (отказ прокси 403). Общий и отдельные проекты загружены и проверены библиотекой `metadata-json` организации StarUML без ошибок встроенного валидатора; проверена визуализация трёх диаграмм её движком. Открытие в графическом StarUML и совместимость с конкретной актуальной версией интерфейса не подтверждены. Если требуются снимки именно окна программы, их необходимо сделать после открытия проекта; порядок приведён в памятке.
