# Лабораторная работа №2 — мастерская ремонта техники

Разработка диаграмм поведения по методическим указаниям Н. В. Барклаевской, 2026. Продолжение первой работы по информационной системе мастерской ремонта техники.

В каталоге `diagrams/` каждая диаграмма представлена отдельно в MDJ, SVG, PNG и PDF:

1. `01_states` — состояния объекта «Заказ на ремонт».
2. `02_application` — активность «Оформление заявки на ремонт» с выделением сущностей.
3. `03_diagnosis` — активность с дорожками «Диагностика и согласование стоимости» с выделением сущностей.

Титул и стиль сохранены из первой работы: группа 4417, М. П. Курбатов, кафедра 41.

**Проверка в программе:** общий проект и три отдельных проекта открыты, визуально проверены и сохранены в настоящем StarUML 7.1.1 для Linux. Встроенный валидатор StarUML не обнаружил ошибок. Технические результаты записаны в `staruml-gui-validation.json` и `model-validation.txt`.

В отчёт вставлены настоящие снимки окна StarUML из каталога `screenshots/`. Они получены захватом окна программы, без перерисовки интерфейса или монтажа. Отдельные экспорты SVG, PNG и PDF созданы самим StarUML.

Использован официальный пробный режим StarUML. Штатные водяные знаки экспорта, если они добавлены программой, сохранены. Проверенная версия — 7.1.1; открытие в Windows-версии 6.0.1 отдельно не проверялось.
