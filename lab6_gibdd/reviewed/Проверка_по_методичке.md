## Проверка логики SQL

Процедура соответствует описанию: при NULL и годах вне 1901–2155 выдаёт сообщение; при допустимом годе проходит 12 месяцев и суммирует COUNT из accidents. Увеличение v_month есть, поэтому цикл завершается. Перед проверкой @lr6_total сбрасывается в NULL, что исключает старый успешный итог при ошибке. COUNT считает сами ДТП, не участия автомобилей. Исходные таблицы процедура не меняет.

Перебор месяцев избыточен для обычного годового COUNT, но здесь оправдан требованием методички показать программный цикл. Временные таблицы, функции из седьмой работы и сложные обработчики для шестой работы не обязательны.
