Одна простая процедура `lr6_simple_year`: IF, WHILE, локальные переменные
и сессионная @lr6_total. Только шестая работа, без функций из седьмой.

Основная часть отчёта: Times New Roman 14 пт, интервал 1,5, красная строка
1,25 см. Поля: слева 3 см, справа 1,5 см, сверху/снизу 2 см. Код Courier New
14 пт; заголовки, таблицы и подписи без красной строки. Рисунки по центру,
подписи снизу. Исходный титульник пятой работы сохранён полностью,
включая прежние номер и тему. Шесть мест оставлены для своих снимков.

В существующей gibdd выполнить целиком 01_процедура.sql,
затем по инструкции запросы 02_тесты_и_скриншоты.sql.
Блок-схема уже вставлена в отчёт; .drawio открывается в diagrams.net.
SQL проверен на MySQL 8.0.46; результаты приложены.
