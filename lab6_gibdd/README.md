- [Отчёт Word](Отчет_ЛР6_ГИБДД.docx)
- [Отчёт PDF](Отчет_ЛР6_ГИБДД.pdf)

В базе `gibdd` из работ № 4–5 выполнить `01_procedures.sql`, затем
`02_positive_tests.sql`. В `03_negative_tests.sql` каждый ошибочный CALL
запускать отдельно. Процедуры не меняют исходные таблицы.

Две процедуры: карточка автомобиля с числом участий в ДТП и сводка ДТП
по 12 месяцам года. Проверено на MySQL 8.0.46: 6 положительных и граничных
вызовов и 7 отрицательных вызовов. Реальные протоколы приложены.

Для сдачи по методичке необходимо добавить собственные скриншоты из
MySQL Workbench; визуализации CLI в отчёте явно обозначены как протоколы.
