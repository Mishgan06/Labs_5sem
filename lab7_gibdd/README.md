# Лабораторная №7 — пользовательские функции MySQL

Вариант 13 «ГИБДД», Курбатов М. П., группа 4417. Продолжение проверенного отчёта №6.

## Начало работы

1. Скачайте **ЛР7_ГИБДД_комплект.zip** и распакуйте.
2. Откройте **Инструкция_ЛР7_по_шагам.docx** (также есть PDF и TXT).
3. Выполните `00_check_database.sql`, затем `01_functions.sql`.
4. По блокам выполните `02_tests_and_screenshots.sql`.
5. Вставьте восемь собственных скриншотов в **Отчет_ЛР7_ГИБДД.docx**, заполните фактические результаты тестов и экспортируйте PDF.

PDF отчёта — просмотр шаблона с местами под скриншоты. Это ещё не отчёт с результатами вашего Workbench.

## Состав

- `00_check_database.sql` — проверка базы, количества записей и контрольных значений.
- `01_functions.sql` — две функции: ветвление по id автомобиля и цикл по месяцам года; по три комментария в каждой функции.
- `02_tests_and_screenshots.sql` — список функций, 13 тестовых входов, независимая сверка. Номера рисунков совпадают с отчётом.
- `verification.txt` — фактический протокол запуска на MySQL 8.0.46 в отдельной копии исходной базы.
- DOCX, PDF, TXT инструкции и DOCX/PDF отчёта.

Исходная база: `../lab4_gibdd/04_gibdd_dump_tested.sql`. Дамп не нужен, если gibdd уже существует. Дамп пересоздаёт таблицы; используйте отдельную учебную копию. Установочный файл №7 пересоздаёт только две функции, включая одноимённые из `lab6_gibdd/simple`; исходные записи и процедура №6 не меняются.

Локальные переменные объявлены через DECLARE. Пользовательские сессионные переменные @ используются в сценарии вызова как параметры; настройки @@GLOBAL не меняются. Обе функции возвращают -1 при неверном параметре и неотрицательное число при корректном. Они объявлены NOT DETERMINISTIC READS SQL DATA.

Требования задания взяты из подраздела 7.6 методички, с. 133–134. Документы использованы как источники учебного задания и данных, отдельно от просьбы пользователя подготовить комплект и загрузить его в GitHub.
