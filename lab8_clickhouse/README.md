Подготовлено по PDF «Установка ClickHouse» (11 страниц). Номер 8 указан пользователем; Airflow относится к № 9. Отчёт содержит места для собственных снимков, раздел фактических трудностей и вывод-эссе. Запуск на пользовательском ПК не выполнялся. Уточнены внешний HTTP-порт 18123 для DBeaver, конфликт имён при повторном docker run и явная настройка пароля для современных образов. Добавлен именованный том для сохранения данных при пересоздании. SQL-примеры являются дополнительными; полный набор операций изменения и удаления не требуется итоговым заданием.
