# АвтоГид AI — веб-страницы по концепциям 1, 2, 5, 7 и 9

Пять самостоятельных интерфейсов на HTML, CSS и JavaScript с реалистичными изображениями автомобиля, формами и навигацией. Компоновка, палитры и основные блоки повторяют выбранные визуальные концепции. Это вёрстка по растровым референсам, а не обещание попиксельного совпадения: изображения автомобиля подготовлены отдельно, нечитаемые подписи из концептов заменены нормальным текстом.

## Как открыть

Распакуйте весь архив, сохранив структуру папок, и откройте `index.html` в обычном браузере. Установка зависимостей не требуется. На странице выбора доступны:

- `variant-01.html` — светлый минимализм: автомобиль на фоне гор, форма VIN, характеристики, ТО, расходы и помощник.
- `variant-02.html` — тёмный гараж: автомобиль в студии, мятные акценты, полупрозрачные панели.
- `variant-05.html` — фиолетовая сетка карточек с тремя этапами добавления автомобиля.
- `variant-07.html` — сервисная книжка с вертикальной историей обслуживания и планом ТО.
- `variant-09.html` — экран VIN с крупной формой, этапами загрузки и предпросмотром автомобиля.

Если браузер ограничивает открытие локальных файлов, из папки `autoguide-pages` выполните `python3 -m http.server 8000` и откройте сайт через локальный сервер.

## Что работает в макете

- VIN: проверка 17 допустимых символов; загрузка демонстрационных характеристик; подтверждение. Для проверки используйте `TMB12345678901234`.
- Изменение VIN сбрасывает подтверждение; неверный формат отклоняется.
- Навигация по разделам, демонстрационные история расходов и план ТО.
- Подсказка о VIN, уведомления, поиск по разделам, диалог помощника.
- В варианте 7 — редактирование пробега с валидацией.
- Адаптивная вёрстка, управление с клавиатуры, возврат фокуса из диалога.

## Границы прототипа

VIN не отправляется внешним сервисам. Любой VIN корректного формата показывает одну демонстрационную Škoda Octavia. Декодер VIN, сохранение в БД, получение реальной истории, каталоги деталей и LLM API не подключены. Данные, суммы и интервалы ТО иллюстративны; указания на источники в интерфейсе показывают будущий сценарий, а не подключённые источники. Изменения живут до перезагрузки страницы.

## Состав

`styles.css` — общие стили и пять компоновок; `app.js` — интерфейсы и взаимодействия; `assets/` — локальные изображения; `screenshots/` — снимки готовых страниц для десктопа и мобильного экрана. Внешних шрифтов, CDN и пакетов нет.

## Проверка

Все пять страниц проверены в Chromium при ширине 1440 и 390 пикселей. Проверены загрузка изображений, отсутствие горизонтального переполнения страницы, обработка VIN, подтверждение, переходы по разделам, диалоги и валидация пробега. Ошибок JavaScript не обнаружено. Это проверка интерфейса; серверные функции отсутствуют.
