# АвтоГид AI — 10 вариантов десктопного дизайна

Откройте `index.html` в браузере: установка и сервер не требуются. Десять кнопок сверху переключают концепции. Варианты отличаются палитрой, навигацией, компоновкой и приоритетом блоков.

1. Светлый минимализм — верхняя навигация, синий акцент.
2. Тёмный гараж — графитовый фон, мятный акцент.
3. Зелёный кабинет — боковая навигация, спокойная зелёная палитра.
4. Премиум — кремовые поверхности, бронзовые акценты.
5. Карточки — крупная модульная сетка, лавандовая палитра.
6. Командный центр — панорамная карточка авто, тёмный синий фон.
7. Сервисная книжка — тёплая палитра и акцент на обслуживании.
8. Маршрут — оранжевые акценты и горизонтальный план ТО.
9. Сканер VIN — крупная форма добавления автомобиля.
10. Диалог с авто — основной акцент на ИИ-помощнике.

## Что можно попробовать

- Переключать концепции и разделы меню.
- Ввести VIN из 17 допустимых символов, например `TMB12345678901234`, загрузить **демонстрационные** характеристики и подтвердить их.
- Изменить пробег. Валидация отклоняет пустое поле и отрицательные значения.
- Посмотреть место для диалога с LLM и ссылок на источники.

Это дизайн-прототип. Декодирование VIN, сохранение в БД, подбор запчастей и LLM API не подключены. Любой корректный по формату VIN показывает одну и ту же демонстрационную карточку автомобиля. Приведённые интервалы ТО и расходы иллюстративны.

`concepts-01-05.png` и `concepts-06-10.png` — обзорные визуальные концепции. `screenshots/` — снимки десяти работающих HTML-вариантов. Изображение автомобиля внутри HTML — встроенная стилизованная SVG-иллюстрация; реалистичные изображения находятся в обзорных концептах.

Рабочее название «АвтоГид AI» можно заменить. Harness относится к процессу разработки и не показывается как функция приложения.
