Версия Airflow 2.9.2 соответствует методичке. Отчёт требует собственных снимков и описания фактических трудностей; запуск на ПК пользователя не выполнялся. Номер 8 указан по просьбе пользователя. Инструкция адаптирована под PowerShell, включает изменения официального Compose, конфликт порта 8080 с прошлой работой, инициализацию и проверку сервисов. Исходный официальный YAML необходимо скачать по ссылке из инструкции; его получение из облачной среды было ограничено сетевым прокси (403). Конфигурация и её запуск в данной среде не проверялись.
