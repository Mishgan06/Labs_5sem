# Учебный навигатор — требования к первой версии

Статус: проект требований для планирования. Реализация и приёмка приложения ещё не подтверждены.

## Предметная область
Учебный каталог помогает студенту найти конспект или практическое задание по дисциплине. Пользователь просматривает материалы и хранит избранное локально в браузере. Добавление материалов в первой версии выполняется редактированием файла данных; учётные записи, платежи и загрузка пользовательских файлов не входят в объём проекта.

## Функциональные требования и критерии приёмки
| ID | Требование | Критерий приёмки |
|---|---|---|
| FR-01 | Просмотр каталога | Каждая запись показывает название, дисциплину и тип материала. |
| FR-02 | Фильтр по дисциплине | При выборе дисциплины видны только относящиеся к ней записи; «Все дисциплины» снимает ограничение. |
| FR-03 | Поиск по названию | Поиск не зависит от регистра, пробелы по краям игнорируются; поиск совместим с фильтром дисциплины. |
| FR-04 | Открытие материала | Кнопка записи открывает соответствующий URL; ссылка и название относятся к одному материалу. |
| FR-05 | Избранное | Пользователь добавляет и удаляет материал; выбор сохраняется после перезагрузки в том же браузере и профиле. |
| FR-06 | Пустая выдача | Если совпадений нет, отображается понятное сообщение и возможность сбросить ограничения. |

## Нефункциональные требования
- NFR-01: при ширине окна 375 px элементы управления доступны, горизонтальная прокрутка страницы не требуется.
- NFR-02: поиск и фильтр доступны с клавиатуры; поля имеют понятные подписи.
- NFR-03: данные избранного хранятся в localStorage, без персональных данных и серверной регистрации.

## Планируемая структура данных
Material: id (строка, уникально), title (строка), discipline (строка), type (строка), url (строка), description (строка).
Favorites: список id выбранных материалов в localStorage.
